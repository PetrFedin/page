## Active portfolio principle

Do not add more broad strategy layers before the next concrete authority/evidence/product slice is built.

Every active product should progress through:

`authoritative data -> deterministic evidence/read model -> user workflow -> executive demo -> partner/API -> network effect`

# Portfolio-wide execution gates

## Gate 1 — Authority
A feature is not live unless its source-of-truth and mutation authority are explicit.

## Gate 2 — Evidence
Every trust/credential/readiness claim must resolve to exact source facts, versions and time.

## Gate 3 — Verification
Where external parties rely on a claim, provide a minimum-disclosure verification surface.

## Gate 4 — Demo
Each active product needs one 7–12 minute executive route showing:
- problem;
- workflow;
- evidence;
- decision;
- measurable value;
- network/enterprise upside.

## Gate 5 — Commercial conversion
Every investor/enterprise demo must end with:
- target buyer;
- pilot scope;
- acceptance criteria;
- implementation dependency;
- pricing unit / commercial model;
- scale path.

## Gate 6 — Network effect
Only after transactional/evidence authority is stable:
- contributor network;
- certification;
- marketplace;
- benchmarking;
- institutional publishing;
- OEM/embedded distribution.
