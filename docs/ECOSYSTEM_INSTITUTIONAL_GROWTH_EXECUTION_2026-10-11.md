## P0 — beautiful, functioning editorial experience
Restore deliberate project order, eliminate blank gaps and duplicated sections, normalize project cards/typography, responsive spacing and RU/EN parity. Keep V1 intact while V2 remains isolated in preview. No bulky framework migration.
Project showcase must use truthful assets: original visual identity for Fashion Management OS and Antiqua; production screenshots only from actually launched, verified apps. Hide unverified screenshots rather than substitute mockups as proof.

## Conversion as a journey
P1: Hero -> selected work -> project case study -> proof -> services and partnership options -> contact. Every case study has verified problem, role, product scope, live status, screenshots if verified, relevant metric source and one next action. Distinguish concept, prototype, live and production.
P1: Lightweight investor/partner data room: exportable one-pager and evidence links, current capabilities, demo golden path, technical maturity and contact; private details only via explicit access.
P1: SEO & international discovery: RU/EN editorial review, canonical/hreflang, structured data, accessibility, OG cards, image optimization and reduced-motion support.
P2: Optional cross-project discovery: common industry taxonomy and relevant related projects; do not create a new cross-product identity database solely for a portfolio.
P2: Consent-respecting funnel analytics measuring engaged project views -> qualified contacts; do not deploy intrusive tracking.

## Quality/admission
Snapshot desktop/tablet/phone using running V2, Playwright diff, broken-link test, Lighthouse budgets and keyboard audit. Content owners/project reviewers share existing publication status; no fake completion badges, invented logos or duplicated screenshots. Release only after preview sign-off.
